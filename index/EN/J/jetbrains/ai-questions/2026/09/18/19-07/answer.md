Да, у JetBrains есть **два отличных решения** под эту задачу — в зависимости от того, хотите ли вы отдельное приложение или инструмент внутри вашей привычной IDE (например, PhpStorm или IntelliJ IDEA).

---

### 1. JetBrains Fleet (Отдельное лёгкое приложение)

**JetBrains Fleet** — это лёгкий быстрая альтернатива VS Code, созданная JetBrains с нуля.

* **Как работает по умолчанию:** Он запускается за пару секунд как простой текстовый редактор с минималистичным интерфейсом. По умолчанию «умный режим» (Smart Mode) отключен, поэтому Fleet **не индексирует весь проект**, не ищет глубокие связи и ничего не компилирует.
* **Что делает:** Подсвечивает синтаксис практически для любых языков программирования, поддерживает вкладки, поиск по тексту, файлы `.markdown` с превью и базовое форматирование.
* **Если понадобятся связи:** В углу экрана есть кнопка включения «Smart Mode» — только если вы сами захотите превратить его в полноценную IDE с автодополнением и индексацией.

---

### 2. Режим LightEdit (Внутри вашей текущей IDE)

Если у вас уже установлена любая IDE от JetBrains (PhpStorm, WebStorm, IntelliJ IDEA и др.), вам даже не нужно скачивать отдельные программы. В них встроен специальный текстовый режим — **LightEdit**.

* **Как работает:** В этом режиме IDE открывает отдельный одиночный файл **без загрузки проекта**, без создания служебных папок `.idea`, без индексации и без поиска связей.
* **Особенности:** Окно IDE очищается от всех лишних панелей (дерева проекта, терминала, запускников). Остается только сам код с качественной подсветкой синтаксиса, подсчетом строк и возможностью быстро переходить по номерам строк (`Ctrl + G`).

#### Как открыть файл в режиме LightEdit:

1. **Через терминал (Linux / macOS / Windows):**
   Запустите команду IDE с флагом `-e` (от слова *edit*):
```bash
phpstorm -e path/to/file.js
# или для IntelliJ IDEA:
idea -e path/to/file.js

```


2. **Через контекстное меню ОС:**
   Вы можете настроить открывание отдельных файлов (например, `.log`, `.txt`, `.json`) через ассоциированное приложение в системе — IDE автоматически поймет, что файл открывается одиночно вне контекста проекта, и запустит его в режиме LightEdit.

---

### Что выбрать?

* Если нужен **отдельный независимый редактор** для быстрых заметок и правки файлов на лету — устанавливайте **JetBrains Fleet**.
* Если не хотите ставить новый софт и нужно просто **быстро взглянуть на одиночный файл** — используйте команду `phpstorm -e filename` для вызова **LightEdit**.
