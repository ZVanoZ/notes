# About

Этот документя является кратким обзором программы "OBS Studio".

## Что такое "OBS Studio" и зачем нужна эта программа

OBS Studio (Open Broadcaster Software) — это бесплатная и открытая программа для записи видео и потокового вещания (стриминга). Она является стандартом в индустрии и позволяет захватывать изображение с экрана, веб-камеры, микрофона, игр и других источников, создавая профессиональные композиции сцен.

## Установка

### Linux

Для установки OBS Studio в Ubuntu и производных дистрибутивах используйте следующую команду в терминале:
```shell
sudo apt install obs-studio
```
Дополнительные инструкции для других дистрибутивов можно найти в официальных репозиториях или используя Flatpak.

### Windows

Для установки OBS Studio на Windows:
1. Перейдите на официальный сайт [obsproject.com](https://obsproject.com/).
2. Скачайте инсталлятор для Windows.
3. Запустите скачанный файл и следуйте инструкциям мастера установки.
4. После завершения запустите программу через ярлык на рабочем столе.
