# Кнопка аварийного стопа на CTRL-DRIVE / CNCDrive CW100 (CW100-T5.5GB)

Инструкция по выбору кнопки, проводке и настройке инвертора. Основана на руководстве CW100 V1.0 (гл. 4 — клеммы, гл. 6 — P4/P5/P8/P9, гл. 7.2 — Err15).

> **Важно.** Дискретный вход CW100 — это **функциональный** стоп, а не сертифицированный Safe Torque Off (STO) и не цепь категории безопасности по ISO 13850 / IEC 60204-1. Обрыв провода к DI останавливает привод только если выбрана **нормально замкнутая** функция (см. ниже). Для станка с требованиями к безопасности нужна отдельная цепь: реле безопасности + контактор, отключающий питание **R/S/T** (или VFD со STO).

Работу с клеммами выполнять при снятом питании. После отключения подождать **не менее 3 минут** (заряд в звене постоянного тока).

---

## 1. Какая кнопка нужна

### Кратко

| Параметр | Рекомендация |
| --- | --- |
| Тип контакта | **Нормально замкнутый (НЗ / NC)** |
| Напряжение цепи | **24 В постоянного тока** с клеммы **24V** инвертора |
| Ток контакта | Цепь DI потребляет **единицы–десятки мА** (для DI1 ≈ **24 мА**). Подойдёт любая промышленная кнопка **24 В DC, ≥ 1 А** |
| Механика | Грибовидная, **с фиксацией** (нужно повернуть/вытянуть, чтобы снять), красный толкатель на жёлтом фоне |

**Нормально разомкнутую (НО / NO) кнопку для аварийного стопа не используйте:** обрыв провода или плохой контакт не остановят двигатель.

### Почему именно НЗ

В списке функций DI есть две «внешние аварии»:

| Функция DI | Имя в руководстве | Когда срабатывает |
| --- | --- | --- |
| **33** | Нормально замкнутый (NC) вход внешней аварии | Когда цепь **разомкнута** (нажата кнопка, обрыв провода, разъём вынут) |
| **11** | Нормально разомкнутый (NO) вход внешней аварии | Когда цепь **замкнута** (нажата НО-кнопка). Обрыв провода **не** даёт аварию |

Для аварийного стопа нужна функция **33** и кнопка с контактом **НЗ**.

### Напряжение

Клемма **24V–GND** инвертора: внешний источник **+24 В**, «обычно питает клеммы DI/DO и внешние датчики». **Максимальный выходной ток: 200 мА.**

Входы DI2–DI4: диапазон уровневого сигнала **5–30 В**. Кнопка должна коммутировать **24 В DC**, не сеть 220/380 В на клеммы DI.

DI1: входное сопротивление **1 кОм** → при 24 В ток ≈ **24 мА**. Для DI2–DI5 ток входа в руководстве не указан; ориентир — единицы–десятки миллиампер (оптопара). Нагрузка на контакт кнопки ничтожна.

Запас по источнику 24 В: одна кнопка E-stop занимает доли процента от лимита **200 мА**.

### Ток и тип контактов кнопки

Берите стандартную промышленную кнопку аварийного останова:

- контакты **1 НЗ** минимум; лучше **1 НЗ + 1 НО** (второй контакт — на лампу, ПЛК или катушку контактора);
- номинал контакта: **24 В DC, не менее 1 А** (категория DC-13 по IEC 60947-5-1 — с запасом);
- фиксация: после нажатия контакт остаётся разомкнутым, пока оператор **не снимет фиксацию** вручную.

Не берите кнопку без фиксации (как обычный «стоп» на пульте): по ISO 13850 аварийный стоп должен оставаться активным до сознательного сброса.

Не коммутируйте сетью 230/400 В контакты, которые идут на DI. Если второй контакт кнопки рвёт катушку контактора питания инвертора — номинал этого контакта должен соответствовать **напряжению и току катушки** (часто 230 В AC), а не 24 В DI.

## 2. Как настроить инвертор

Рекомендуемый вариант: свободный вход DI (ниже — **DI5**) + функция **33** + заводской активный **высокий** уровень.

### 2.1. Какие клеммы занять

Заводская раскладка DI:

| Параметр | Клемма | Заводская функция | Для E-stop |
| --- | --- | --- | --- |
| **P4-00** | DI1 | 1 — FWD / RUN | не трогать |
| **P4-01** | DI2 | 2 — REV / направление | не трогать |
| **P4-02** | DI3 | 4 — FJOG | не трогать |
| **P4-03** | DI4 | 9 — сброс аварии (RESET) | **оставить**: сброс после E-stop |
| **P4-04** | DI5 | 12 — многоступенчатое задание 1 | **переназначить на 33** |

Если DI5 уже занят (HDI / ступени частоты), поставьте функцию **33** на любую другую свободную DI через **P4-00…P4-04**. Параметры со свойством **★** меняются только на остановленном приводе.

### 2.2. Проводка (питание снято)

Заводской **P4-38 = 00000**: активен **высокий** уровень (единицы = DI1, …, десятки тысяч = DI5). С функцией **33** это означает:

- замкнутый НЗ-контакт подаёт **+24 В** на DI → «петля цела» → аварии нет;
- разомкнутый контакт (нажат E-stop или обрыв) → на DI нет высокого уровня → **Err15**.

```
  24V ----[ кнопка E-stop, контакт НЗ, с фиксацией ]---- DI5
  GND ---------------------------------------------------- общий сигнальный
```

Не кладите этот провод в одну трубу с силовыми кабелями R/S/T и U/V/W. Соблюдайте полярность **24V / GND**.

Если используете не DI5, замените **DI5** на выбранную клемму и соответствующий разряд **P4-38** не инвертируйте.

### 2.3. Параметры

| Код | Значение | Зачем |
| --- | --- | --- |
| **P4-04** | **33** | DI5 = НЗ-вход внешней аварии |
| **P4-38** | **00000** (завод) | высокий уровень активен; не ставить «1» в разряде DI5, иначе логика НЗ перевернётся |
| **P4-10** | **0,01 с** (завод) | фильтр дребезга; для E-stop не увеличивать без нужды |
| **P4-03** | **9** (завод) | DI4 = RESET после аварии |
| **P9-47** | **00000** (завод) | разряд тысяч — действие при **Err15** (авария 15): **0 = выбег**. Выход инвертора снимается сразу, без рампы **P0-18** |
| **P9-09** | **0** (завод) | **запретить автосброс**. Иначе привод сам снимет Err15, пока кнопка ещё нажата или сразу после неё |
| **P8-18** | **1** (рекомендуется; завод **0**) | защита при пуске: после сброса аварии двигатель **не** стартует сам, если команда RUN всё ещё висит на клемме |

Параметры **P4-xx** со свойством **★** и **P8-18** задавать на стопе (**STOP**).

**P9-47** читается по разрядам (завод всё нули):

- единицы — перегрузка двигателя (11);
- десятки — обрыв фазы на входе (12);
- сотни — обрыв фазы на выходе (13);
- **тысячи — авария внешнего оборудования (15)** ← это E-stop через функции 11/33;
- десятки тысяч — авария связи (16).

Для каждой цифры: **0** выбег, **1** останов по **P6-10**, **2** продолжить работу. Для аварийного стопа тысячи должны остаться **0**. Значение **2** («продолжить работу») для Err15 **нельзя**.

### 2.4. Пошаговая настройка

1. Снять питание, подождать 3 минуты. Подключить кнопку: **24V → НЗ-контакт → DI5**, общий **GND**.
2. Подать питание. Убедиться, что кнопка **не** нажата (контакт замкнут).
3. На стопе: **P4-04 = 33**, проверить **P4-38 = 00000**, **P9-09 = 0**, **P9-47 = 00000**, желательно **P8-18 = 1**.
4. Запустить двигатель обычным способом (панель или клеммы).
5. Нажать E-stop: привод должен сразу снять выход (выбег), на панели **Err15** («авария внешнего оборудования»). Индикатор **RUN** погаснуть.
6. Попытка пуска при нажатой кнопке — пуска не должно быть, **Err15** остаётся.
7. Снять фиксацию кнопки (повернуть/вытянуть). **Err15** сам не обязан исчезнуть — нужен сброс.
8. Сброс: клавиша **STOP/RESET** на панели (**P7-02 = 1** с завода — действует в любом режиме) **или** импульс на DI4 (функция **9**). Затем обычный пуск. Если включили **P8-18 = 1**, сначала снимите и снова подайте команду RUN.

Проверка обрыва: отсоединить провод от DI5 на работающем двигателе — тоже **Err15**. Это как раз смысл НЗ-схемы.

### 2.5. Сброс после аварийного стопа

Пока кнопка зафиксирована в нажатом положении, сброс бесполезен: функция **33** снова выставит **Err15**.

Порядок: отпустить кнопку → устранить причину → **RESET** (панель или DI4) → команда пуска.

Код **Err15** в гл. 7.2: «Сигнал внешней аварии подан через DI» / «через виртуальный I/O». Способ устранения в руководстве: «Сбросьте операцию».

## 3. Другие функции DI (не рекомендуется как основной E-stop)

В списке **P4-00** есть ещё имена, похожие на стоп. Их поведение в 44-страничном PDF **не расписано** дальше названия.

| Функция | Имя | Почему это не замена НЗ-аварии |
| --- | --- | --- |
| **47** | Аварийный останов | Есть в списке, алгоритма нет (рампа? выбег? код аварии?). Не проверялось на аппарате |
| **11** | НО-вход внешней аварии | Даёт тот же **Err15**, но **не** fail-safe: обрыв провода не останавливает |
| **8** | Выбег (coast to stop) | Снимает выход, **без** аварии. Отпустил кнопку — при двупроводном RUN двигатель может сразу поехать снова |
| **36** | Внешняя клемма STOP 1 | Обычный стоп (скорее по **P6-10**, с завода плавная рампа), не авария |
| **48** | Внешняя клемма STOP 2 | Тоже только имя; в PDF нет |
| **44 / 45** | Пользовательская авария 1/2 | **Err27 / Err28**, та же идея «сбросьте операцию», без описания НЗ/НО |

Если нужен именно **аварийный** стоп с блокировкой повторного пуска — оставляйте **33 + Err15**, а не функцию **8** или **36**.

## 4. Сигнал «авария» наружу (по желанию)

Реле **TA–TC**: нормально разомкнутый контакт, **250 В перем. тока, 3 А, COSØ = 0,4** или **30 В пост. тока, 1 А**.

| Код | Значение | Смысл |
| --- | --- | --- |
| **P5-02** | **2** | реле = «выход аварии (останов)» |
| **P5-01** | завод **2** | то же на выходе FMR, если **P5-00 = 1** |

Это сигнал для лампы/ПЛК, а не силовое отключение сети.

---

## 5. Пробелы руководства

- Функции **47**, **36**, **48** названы, алгоритм не описан.
- Ток входа DI2–DI5 не нормирован (есть только **5–30 В** и у DI1 сопротивление **1 кОм**).
- Нет схемы «кнопка E-stop → DI». Проводка выше — типовая для **P4-38 = 00000** и функции **33**; перед постоянной эксплуатацией проверить на вашем экземпляре: нажатие и обрыв провода → **Err15**, выбег, нет самозапуска.
- **P9-47** помечен и как настраиваемый (**☆**), и соседние коды P9 — как «измеряемое» (**●**); ориентируйтесь на таблицу: P9-47 имеет диапазон и завод **00000**.
