# Реверс двигателя на CTRL-DRIVE / CNCDrive CW100 (модель CW100-T5.5GB)

Практическая инструкция по смене направления вращения асинхронного двигателя, питаемого преобразователем частоты серии **CW100**. Рабочая модель в этом каталоге — **CW100-T5.5GB**: трёхфазный вход **380 В** (префикс `T`), согласуемый двигатель **5,5 кВт**, номинальный выходной ток по таблице руководства — **13,0 А** (строка `CW100-5D5-4`).

Источник — преобразованное 44-страничное руководство пользователя (EN/RU) из `users-guide/`. В нём есть таблица кодов функций, описание клемм и панели, но **нет** схем двух-/трёхпроводного управления и **нет** карты регистров Modbus. Там, где логика не расписана в исходнике, это явно помечено.

## Меры безопасности

Преобразователь выдаёт на **U, V, W** опасное напряжение и может запустить двигатель **без предупреждения**, если на клеммах уже есть команда RUN.

1. Работы выполняет квалифицированный специалист (гл. 1.2 руководства).
2. Перед любым переключением силовых проводов: снять команду пуска, остановить привод клавишей **STOP / REST** (или внешней STOP), отключить питание, вывесить блокировку, подождать **не менее 3 минут**. В шине сохраняется высокое напряжение; «не снимайте провод и не касайтесь клемм в течение 3 минут после отключения питания».
3. **Не меняйте фазы U/V/W и не трогайте силовые клеммы при включённом питании.** «Подключение не выполнять при включённом питании».
4. Надёжно заземлите клемму **⊕** преобразователя и двигатель.
5. **Запрещено** подключать сеть переменного тока к **U, V, W** — это повреждает преобразователь.
6. Перемена двух входных фаз **R/S/T** направление двигателя **не меняет**: порядок фаз на выходе задаёт инвертор, а не сеть.
7. Перед первой проверкой реверса отцепите нагрузку или убедитесь, что механизм может безопасно крутиться в обе стороны (нет односторонних упоров, насосов, которые нельзя реверсировать, и т. п.).
8. Реверс «на лету» (смена FWD↔REV без останова) вызывает рекуперацию. При коротком времени торможения возможны **Err03 / Err06**. При необходимости увеличьте **P0-18** (время торможения 1) и/или задайте мёртвую зону **P8-12**; для частых реверсов с инерцией используйте тормозной резистор (для T5.5GB руководство рекомендует **≥ 90 Ом, 400 Вт**, модуль встроен).
9. Если реверс в данном механизме недопустим, запретите его параметром **P8-13 = 1** (см. ниже).
10. Для клеммного управления рекомендуется **P8-18 = 1** (защита при пуске): после включения питания привод не стартует сам, пока команду RUN не снимут и не подадут снова.

## Как проверить направление вращения

| Способ | Что смотреть | Откуда в руководстве |
| --- | --- | --- |
| Индикатор панели **F/R** | Светится — **обратное** вращение | Гл. 5.2, пункт 3 |
| Индикатор **RUN** | Светится — привод в работе | Гл. 5.2, пункт 1 |
| Валик / шкив / крыльчатка | Визуально, с безопасного расстояния, на малой частоте | Практика наладки |
| Дискретный выход «Обратное вращение» | Функция **33** в **P5-01** / **P5-02** / **P5-04** | Таблица P5 |
| Мониторинг | **U0-00** рабочая частота, **U0-01** заданная частота, **U0-07** состояние DI, **U0-61** состояние работы | Группа U0 |

Порядок первой проверки:

1. Задайте малую частоту (для JOG заводское **P8-00 = 2,00 Гц**; для обычного пуска временно снизьте **P0-08** или потенциометр).
2. Пуск в «прямом» направлении. Зафиксируйте фактическое вращение вала и состояние **F/R** (должен быть погашен, если **P0-09 = 0** и нет команды REV).
3. Команда реверса. Вал должен изменить направление; **F/R** должен загореться.
4. Останов. Не оставляйте механизм под напряжением без необходимости.

Если направление «наоборот» относительно механики, не путайте **командный реверс** (FWD/REV, клавиша M-FUN) и **инверсию нуля** (**P0-09**): второе меняет смысл «прямого» направления навсегда, пока параметр не вернут.

## Общие параметры, без которых реверс «не слушается»

Эти коды действуют на **все** варианты ниже.

| Код | Имя | Значение для реверса | Завод | Свойство |
| --- | --- | --- | --- | --- |
| **P8-13** | Управление реверсом | **0** — разрешено; **1** — запрещено | 0 | ☆ |
| **P8-12** | Мёртвая зона прямого/обратного вращения | Пауза на нулевой частоте при смене направления, **0,0…3000,0 с** | 0,0 с | ☆ |
| **P0-02** | Выбор источника команды | **0** панель (LED LOC погашен); **1** клеммы (LED горит); **2** связь (LED мигает) | 0 | ☆ |
| **P0-09** | Направление вращения | **0** то же направление; **1** обратное направление (инверсия «прямого») | 0 | ☆ |
| **P7-02** | Функция STOP/RESET | **1** — STOP действует в любом режиме (завод); **0** — только с панели | 1 | ☆ |

Свойства из руководства: **☆** можно менять на ходу и на стопе; **★** только на стопе.

Пока **P8-13 = 1**, команды обратного вращения (клемма REV, RJOG, M-FUN в режиме реверса, отрицательное задание — если привод его трактует как реверс) не должны давать обратного хода. Точную реакцию при запрете (игнор / останов / только вперёд) 44-страничное руководство **не описывает** — проверяйте на стенде.

## Как менять параметр с панели

1. Клавиша **PROG / PRG** — вход в меню уровня I (или выход).
2. **▲ / ▼** — выбор группы и кода (`P0`, `P4`, `P8`…).
3. **ENTER** — вход в значение.
4. **SHIFT** — выбор разряда; **▲ / ▼** — изменение.
5. **ENTER** — запись.
6. **PRG** — выход.

Если **PP-00 ≠ 0**, сначала введите пароль. Параметры со свойством **★** (в том числе **P4-00…P4-04**, **P4-11**, **P7-01**) **нельзя** менять во время работы: сначала **STOP**.

## 1. Краткий перечень всех вариантов реализации

| № | Вариант | Когда применять | Главные коды |
| ---: | --- | --- | --- |
| 1 | Инверсия «прямого» направления **P0-09** | Один раз скорректировать «вперёд» под механику, не трогая кабель | P0-09, P8-13 |
| 2 | Клавиша панели **M-FUN** (она же **MF.K**) как FWD↔REV | Пуск с панели, нужен оперативный реверс без клемм | P0-02=0, P7-01=2 |
| 3 | Обратный JOG с панели | Краткий толчок назад при наладке | P0-02=0, P7-01=4, P8-00…P8-02 |
| 4 | Клеммы, **двухпроводный режим 1** | Две кнопки/реле: отдельно вперёд и назад (уровни) | P0-02=1, P4-11=0, функции DI 1 и 2 |
| 5 | Клеммы, **двухпроводный режим 2** (заводской) | Одна команда RUN + одна команда направления | P0-02=1, P4-11=1, функции DI 1 и 2 |
| 6 | Клеммы, **трёхпроводный режим 1** | Импульсный пуск вперёд/назад + удерживаемый STOP (НЗ) | P0-02=1, P4-11=2, функции DI 1, 2 и 3 |
| 7 | Клеммный обратный JOG (**RJOG**) | Толчок назад с пульта/станка, параллельно основному RUN | функция DI = 5, P8-00…P8-02, P8-27 |
| 8 | Команда по связи (Modbus-RTU, группа **PD**) | ПЛК / ЧПУ задаёт пуск и направление по RS-485 | P0-02=2, PD-00…PD-06 |
| 9 | Знаковое задание частоты (AI / HDI / PC / PID) | Реверс знаком задания (−%), без отдельной клеммы REV | кривые P4, PC-00…PC-15, PA-08, P8-13 |
| 10 | Перемена двух фаз **U/V/W** | Крайний электромонтажный способ «развернуть мотор» | силовые клеммы; питание снято |

Аналоговый вход **сам по себе команду пуска не даёт**: источник команды (**P0-02**) и источник частоты (**P0-03**) — разные вещи. Реверс «с потенциометра» возможен только если кривая AI даёт отрицательную установку **и** привод уже получил команду RUN.

## 2. Вариант 1. Инверсия направления параметром P0-09

### Когда использовать

Механика крутится «не в ту сторону» относительно ожидаемого «вперёд», а кабель U/V/W уже проложен и его нежелательно переделывать. Это **не** оперативный реверс, а сдвиг нуля направления.

### Параметры

| Код | Имя | Что поставить | Завод |
| --- | --- | --- | --- |
| **P0-09** | Направление вращения | **0** — то же направление; **1** — обратное направление | 0 |
| **P8-13** | Управление реверсом | **0** (иначе обратное направление может быть блокировано) | 0 |

Свойство **P0-09**: ☆ (можно менять и на ходу — но на работающем механизме этого лучше не делать).

### Проводка

Не требуется. Силовой кабель **U/V/W** не трогать.

### Пошагово

1. Остановить привод (**STOP**), убедиться что **RUN** погашен.
2. Проверить **P8-13 = 0**.
3. Записать исходное **P0-09** (обычно 0).
4. Установить **P0-09 = 1**.
5. Пуск той же командой, что раньше считалась «прямой» (клавиша **RUN** при **P0-02 = 0**, либо клемма FWD).
6. Вал должен вращаться в противоположную сторону относительно шага «до смены». Индикатор **F/R**: руководство говорит «светится — обратное вращение»; как именно **P0-09** влияет на **F/R**, исходник **не поясняет** — ориентируйтесь на вал.

### Проверка и откат

Вернуть **P0-09 = 0**. Если после инверсии «прямой» ход совпал с механикой, оперативный реверс по-прежнему делается вариантами 2–9: они инвертируют уже новое «прямое» направление.

### Предупреждения

- Смена **P0-09** на работающем приводе — внезапное изменение направления.
- Не комбинируйте бездумно с перестановкой фаз U/V/W: два «исправления» взаимно отменятся.

## 3. Вариант 2. Реверс клавишей панели M-FUN (P7-01 = 2)

### Когда использовать

Источник команды — панель (**P0-02 = 0**). Нужно переключать направление с клавиатуры. Отдельной клавиши FWD/REV на панели **нет**: направление вешается на многофункциональную **M-FUN**. В таблице параметров эта же клавиша названа **MF.K**.

### Параметры

| Код | Имя | Значение | Завод | Свойство |
| --- | --- | --- | --- | --- |
| **P0-02** | Выбор источника команды | **0** — управление с панели | 0 | ☆ |
| **P7-01** | Выбор функции клавиши MF.K | **2** — переключение прямого и обратного вращения | 0 | ★ |
| **P8-13** | Управление реверсом | **0** — разрешено | 0 | ☆ |
| **P0-03** | Основной источник частоты X | Любой нужный (завод **3** — AI2, местный потенциометр) | 3 | ★ |
| **P0-08** | Заданная частота | Если **P0-03 = 0** или **1** | 50,00 Гц | ☆ |

Описание клавиши в гл. 5.3: «Может быть задано как источник команды или как быстрое переключение направления согласно P7-01».

### Проводка

Не требуется.

### Пошагово

1. Остановить привод. Задать **P7-01 = 2** (только на стопе, ★).
2. Убедиться **P0-02 = 0**, **P8-13 = 0**.
3. Задать безопасную частоту.
4. Нажать **RUN** — пуск в текущем направлении (**F/R** погашен при «прямом» и **P0-09 = 0**).
5. Нажать **M-FUN** — направление должно смениться, **F/R** загореться (или наоборот).
6. **STOP / REST** — останов.

Точное поведение **M-FUN** при останове (меняет ли «направление по умолчанию» для следующего **RUN** или действует только на ходу) руководство **не описывает**. Проверьте оба случая на стенде.

### Проверка

Цикл: прямой ход → **M-FUN** → обратный ход → **STOP**. Индикатор **F/R** и вал согласованы.

### Предупреждения

- Заводское **P7-01 = 0** — клавиша отключена; без смены параметра реверса с панели нет.
- **P7-01 = 1** — это **не** реверс, а переключение «панель / дистанционно (клеммы или связь)».
- Случайное нажатие **M-FUN** на ходу даст реверс. После наладки верните **P7-01 = 0**, если оперативный реверс с панели не нужен.

## 4. Вариант 3. Обратный JOG с панели (P7-01 = 4)

### Когда использовать

Кратковременный толчок в обратную сторону при выставке механизма. JOG идёт на частоте **P8-00**, с своими временами разгона/торможения, а не на рабочей **P0-08**.

### Параметры

| Код | Имя | Значение | Завод | Свойство |
| --- | --- | --- | --- | --- |
| **P0-02** | Источник команды | **0** панель | 0 | ☆ |
| **P7-01** | Функция MF.K | **4** — обратный JOG; (**3** — прямой JOG) | 0 | ★ |
| **P8-00** | Частота работы JOG | 0,00 Гц … макс. частота; завод **2,00 Гц** | 2,00 Гц | ☆ |
| **P8-01** | Время разгона JOG | 0,0…6500,0 с | 20,0 с | ☆ |
| **P8-02** | Время торможения JOG | 0,0…6500,0 с | 20,0 с | ☆ |
| **P8-13** | Управление реверсом | **0** | 0 | ☆ |

### Пошагово

1. На стопе: **P7-01 = 4**, **P0-02 = 0**, **P8-13 = 0**.
2. При необходимости уменьшить **P8-00** и **P8-01 / P8-02** (заводские 20 с для толчка часто слишком длинные — это уже решение наладчика, не требование руководства).
3. Удерживать **M-FUN**: двигатель должен крутиться назад на частоте JOG, **F/R** светится.
4. Отпустить **M-FUN**: останов по **P8-02**.

Удержание «пока нажата» для JOG с панели в руководстве **не сформулировано явно**; так устроен типичный JOG этой линейки параметров. Если привод остаётся в RUN после отпускания — сразу **STOP** и не используйте этот режим, пока не проверите поведение.

### Проверка

Короткий толчок, вал назад, **F/R** включён, после отпускания — останов.

### Предупреждения

- **P7-01** нельзя сменить на ходу (★).
- JOG игнорирует обычную заданную частоту **P0-08**.

## 5. Вариант 4. Клеммы: двухпроводный режим 1 (P4-11 = 0)

Две независимые уровневые команды: «прямой RUN» и «обратный RUN».

### Когда использовать

Внешний пульт или ПЛК с двумя выходами «вперёд» / «назад». Одновременно обе команды активны быть не должны (типовая обработка — останов; **в руководстве CW100 таблицы истинности нет**).

### Заводская раскладка DI

Из руководства: DI1–DI5 делят один список функций. Завод:

| Параметр | Клемма | Заводская функция |
| --- | --- | --- |
| **P4-00 = 1** | DI1 | Прямой RUN (**FWD**) или RUN |
| **P4-01 = 2** | DI2 | Обратный RUN (**REV**) или направление RUN |
| **P4-02 = 4** | DI3 | Прямой JOG (FJOG) |
| **P4-03 = 9** | DI4 | Сброс аварии (RESET) |
| **P4-04 = 12** | DI5 | Многоступенчатое задание 1 |

Для этого варианта **DI1 = 1** и **DI2 = 2** уже подходят. Менять их нужно только если клеммы заняты иначе.

### Параметры

| Код | Имя | Значение | Завод | Свойство |
| --- | --- | --- | --- | --- |
| **P0-02** | Источник команды | **1** — клеммы | 0 | ☆ |
| **P4-11** | Режим клеммной команды | **0** — двухпроводный режим 1 | **1** | ★ |
| **P4-00** | Функция DI1 | **1** — FWD / RUN | 1 | ★ |
| **P4-01** | Функция DI2 | **2** — REV / направление | 2 | ★ |
| **P4-38** | Активный уровень DI | Завод **00000** — активен **высокий** уровень (единицы=DI1, десятки=DI2, …) | 00000 | ★ |
| **P4-10** | Фильтр DI | 0,000…1,000 с | 0,01 с | ☆ |
| **P8-13** | Реверс | **0** разрешён | 0 | ☆ |
| **P8-12** | Мёртвая зона FWD/REV | по необходимости | 0,0 с | ☆ |
| **P8-18** | Защита при пуске | рекомендуется **1** | 0 | ☆ |

**P4-11** по умолчанию равен **1** (режим 2). Для режима 1 его **обязательно** сменить на **0** на остановленном приводе.

### Проводка

Питание дискретных входов: клеммы **24V–GND** («обычно питает клеммы DI/DO», макс. **200 мА**). Диапазон уровневого входа DI2–DI4: **5–30 В**. Сопротивление DI1: **1 кОм**.

При заводском **P4-38 = 00000** (высокий уровень активен) типовая схема — замыкание входа на **+24 В**, общий **GND**:

```
                    +24V
                      |
        +-------------+-------------+
        |                           |
       SB_F                       SB_R
     (вперёд)                    (назад)
        |                           |
       DI1                         DI2
        |                           |
       GND ------------------------+  (общий 0 В управления)
```

Полярность и «высокий/низкий» задаёт **P4-38**. Руководство требует соблюдать напряжение и полярность клемм. Не кладите силовые и сигнальные кабели в одну трубу.

Имена функций в **P4-00**: «**1: Прямой RUN (FWD) или RUN**», «**2: Обратный RUN (REV) или направление RUN**». В режиме 1 обычно действует левая часть имён: FWD и REV.

### Типовая логика (нет в 44-страничном руководстве)

Ниже — стандартная расшифровка «двухпроводный режим 1» для той же линейки имён функций. **Обязательно проверьте на своём аппарате.**

| DI1 (FWD) | DI2 (REV) | Ожидаемое действие |
| --- | --- | --- |
| 0 | 0 | Стоп |
| 1 | 0 | Прямой ход |
| 0 | 1 | Обратный ход |
| 1 | 1 | Обычно стоп (взаимоблокировка) |

### Пошагово

1. Снять питание, подождать 3 минуты, смонтировать DI1/DI2 и **GND/24V**.
2. Подать питание. На стопе: **P0-02 = 1**, **P4-11 = 0**, **P4-00 = 1**, **P4-01 = 2**, **P8-13 = 0**.
3. Задать частоту (**P0-03** / потенциометр / **P0-08**).
4. Замкнуть только DI1 — прямой ход, **F/R** погашен.
5. Разомкнуть DI1, дождаться останова (или использовать **P8-12** при смене на лету).
6. Замкнуть только DI2 — обратный ход, **F/R** светится.
7. Проверить U0-07 (состояние DI) при сомнениях в проводке.

### Предупреждения

- После смены **P0-02** на 1 клавиша **RUN** больше не является источником пуска. Аварийный стоп с панели зависит от **P7-02** (завод 1 — STOP действует всегда).
- Если клемма RUN уже замкнута в момент включения — возможен самозапуск. Включите **P8-18 = 1**.
- Задержки **P4-35 / P4-36** (DI1/DI2) по умолчанию 0; ненулевая задержка «откладывает» реверс.

## 6. Вариант 5. Клеммы: двухпроводный режим 2 (P4-11 = 1) — заводской

Одна клемма — команда **RUN**, вторая — **направление**. Это заводской **P4-11**.

### Когда использовать

Типовой станок: тумблер «вперёд/назад» и отдельная кнопка или контактор «работа». Совпадает с правой частью имён функций: «RUN» и «направление RUN».

### Параметры

Те же, что в варианте 4, кроме:

| Код | Значение |
| --- | --- |
| **P4-11** | **1** — двухпроводный режим 2 (**завод, менять не нужно**) |
| **P0-02** | **1** |
| **P4-00** | **1** (DI1 = RUN) |
| **P4-01** | **2** (DI2 = направление) |

### Проводка

```
                    +24V
                      |
        +-------------+-------------+
        |                           |
      SB_RUN                     SA_DIR
     (работа)                 (направление)
        |                           |
       DI1                         DI2
        |                           |
       GND ------------------------+
```

### Типовая логика (нет схемы в руководстве CW100)

| DI1 (RUN) | DI2 (направление) | Ожидаемое действие |
| --- | --- | --- |
| 0 | 0 | Стоп |
| 0 | 1 | Стоп (направления без RUN недостаточно) |
| 1 | 0 | Прямой ход |
| 1 | 1 | Обратный ход |

### Пошагово

1. Монтаж как выше, питание снято.
2. **P0-02 = 1**, **P4-11 = 1**, функции DI1/DI2 заводские, **P8-13 = 0**.
3. DI2 разомкнут, замкнуть DI1 — вперёд.
4. Не размыкая DI1, замкнуть DI2 — реверс через **P8-12** и времена **P0-17 / P0-18**.
5. Разомкнуть DI1 — стоп независимо от DI2.

### Проверка

U0-07 меняется при каждом контакте; **F/R** следует за DI2 только пока DI1 активен.

### Предупреждения

- Частая ошибка: оставить **P0-02 = 0** и ждать реакции на клеммы — клеммы в этом случае не являются источником команды.
- Частая ошибка: оставить **P4-11 = 0**, думая что завод уже «RUN + направление». Завод как раз режим 2, но если кто-то выставил режим 1, DI2 снова станет самостоятельным REV и одновременное замыкание DI1+DI2 даст другую логику.

## 7. Вариант 6. Клеммы: трёхпроводный режим 1 (P4-11 = 2)

Импульсный пуск вперёд и назад плюс отдельная клемма разрешения/стопа.

### Когда использовать

Пульт с кнопками без фиксации: «Вперёд», «Назад», «Стоп» (стоп обычно **нормально замкнутый**). Нужна функция DI **3 — трёхпроводное управление**.

Заводской DI3 занят FJOG (**P4-02 = 4**). Для трёхпроводки одну клемму (часто DI3) надо переназначить.

### Параметры

| Код | Имя | Значение | Свойство |
| --- | --- | --- | --- |
| **P0-02** | Источник команды | **1** | ☆ |
| **P4-11** | Режим клеммной команды | **2** — трёхпроводный режим 1 | ★ |
| **P4-00** | DI1 | **1** — FWD (импульс пуска вперёд) | ★ |
| **P4-01** | DI2 | **2** — REV (импульс пуска назад) | ★ |
| **P4-02** | DI3 | **3** — трёхпроводное управление (цепь STOP/разрешения) | ★ |
| **P8-13** | Реверс | **0** | ☆ |
| **P8-12** | Мёртвая зона | по необходимости | ☆ |

Клеммы DI можно назначить иначе (любая DI1–DI5), но три функции **1, 2 и 3** должны быть назначены **одновременно**. В руководстве есть только «трёхпроводный режим 1»; режима 2 в списке **P4-11 нет**.

### Проводка (типовая; схемы в CW100-мануале нет)

```
  +24V ---- SB_STOP (НЗ) ---- DI3   функция 3, трёхпроводное управление
  +24V ---- SB_FWD  (НО, импульс) -- DI1   функция 1
  +24V ---- SB_REV  (НО, импульс) -- DI2   функция 2
  GND  ----------------------------- общий
```

Типовая логика семейства:

- Цепь на клемме функции **3** должна быть **замкнута** (кнопка стопа НЗ не нажата) — иначе пуск невозможен.
- Короткое замыкание DI1 — защёлка прямого хода.
- Короткое замыкание DI2 — защёлка обратного хода.
- Размыкание DI3 (нажат стоп) — останов.

**Это не цитата из 44-страничного CW100.** Проверьте: удерживается ли ход после отпускания импульсной кнопки; что происходит при импульсе REV во время прямого хода; нужен ли НЗ именно на функции 3.

### Пошагово

1. Монтаж трёх кнопок, питание снято.
2. На стопе: **P0-02 = 1**, **P4-11 = 2**, назначить функции **1, 2, 3**.
3. Цепь STOP замкнута. Импульс FWD — прямой ход.
4. Импульс REV — реверс (через **P8-12**).
5. Нажать STOP (разомкнуть DI3) — останов.
6. Попытка пуска при разомкнутом DI3 не должна запускать двигатель.

### Предупреждения

- Забыли назначить функцию **3** — значение **P4-11 = 2** без клеммы «трёхпроводное управление» обычно не работает предсказуемо.
- НЗ-стоп нельзя обходить перемычкой «навсегда»: это снимает защиту.
- **P4-38**: если инвертировать активный уровень клеммы STOP, логика НЗ/НО перевернётся.

## 8. Вариант 7. Клеммный обратный JOG (функция DI = 5, RJOG)

### Когда использовать

Толчок назад с выносной кнопки, в том числе когда основной режим — панель или другой источник. Заводской **DI3 = FJOG (4)**; для реверса JOG нужна функция **5**.

### Параметры

| Код | Имя | Значение | Завод |
| --- | --- | --- | --- |
| Функция выбранной DI (**P4-00…P4-04**) | **5** — обратный JOG (RJOG) | DI3 завод = **4** (FJOG) |
| **P8-00 / P8-01 / P8-02** | Частота и времена JOG | 2,00 Гц / 20,0 с / 20,0 с |
| **P8-27** | Приоритет клеммного JOG | **0** запрещён; **1** разрешён | 0 |
| **P8-13** | Реверс | **0** | 0 |

**P0-02**: руководство не уточняет, действует ли клеммный JOG при источнике «панель» или только при «клеммы». Есть отдельный **P8-27** «приоритет клеммного JOG» — это намекает, что JOG с клеммы может перебивать текущий режим, но **только если P8-27 = 1**. Безопасная наладка: **P0-02 = 1** и/или явно **P8-27 = 1**, затем проверка.

Прямой JOG — функция **4 (FJOG)**; обратный — **5 (RJOG)**.

### Проводка

Кнопка без фиксации между **+24 В** и выбранным DIx (при высоком активном уровне), общий **GND**.

Заводский DI3 уже «JOG», но прямой. Пример переназначения DI3 на реверс-толчок:

- **P4-02 = 5** (RJOG вместо FJOG).

Либо оставить DI3 как FJOG и назначить RJOG на свободную клемму (DI5: сменить **P4-04** с 12 на 5, если многоступенчатое задание не нужно).

### Пошагово

1. На стопе назначить функцию **5** на выбранный DI.
2. **P8-13 = 0**. Решить, нужен ли **P8-27 = 1**.
3. Задать **P8-00** (малая частота).
4. Нажать и удерживать кнопку RJOG — вал назад, **F/R** включён.
5. Отпустить — останов по **P8-02**.

### Предупреждения

- При **P8-27 = 1** клеммный JOG может внезапно перехватить управление у панели/ПЛК.
- Не держите FJOG и RJOG одновременно.

## 9. Вариант 8. Реверс по связи (Modbus-RTU, группа PD)

### Когда использовать

ПЛК, ЧПУ или ПК задаёт пуск и направление по **RS-485**. Клеммы связи: **A+**, **B−**, протокол **MODBUS-RTU** (таблица 4-2).

### Что есть в руководстве

| Код | Имя | Нужные значения | Завод |
| --- | --- | --- | --- |
| **P0-02** | Источник команды | **2** — управление по связи (LED LOC мигает) | 0 |
| **P0-03** | Источник частоты X | **9** — если частоту тоже задаёт связь | 3 |
| **PD-00** | Скорость обмена | Единицы = Modbus: 0…9 = 300…115200 бод. Завод **6005** → единицы **5** = **9600** | 6005 |
| **PD-01** | Формат данных MODBUS | 0: 8N2; 1: 8E1; 2: 8O1; 3: 8N1 | 0 |
| **PD-02** | Локальный адрес | 1…247 (0 = широковещательный) | 1 |
| **PD-03** | Задержка ответа | 0…20 мс | 2 |
| **PD-04** | Таймаут связи | 0,0 = недействительно; иначе 0,1…60,0 с | 0,0 |
| **PD-05** | Протокол Modbus | Единицы: **0** нестандартный; **1** стандартный. Завод **30** → единицы **0** (нестандартный) | 30 |
| **PD-06** | Разрешение тока при чтении | 0: 0,01 А; 1: 0,1 А | 0 |
| **P8-13** | Реверс | **0** | 0 |

Мониторинг задания связи: **U0-28** «Значение установки по связи», единица 0,01 %.

Авария связи: **Err16**. В тексте устранения ошибочно указана «группа **FD**» — в таблице параметров связь это группа **PD**.

### Чего в руководстве нет

Ввод руководства обещает главу «описание протокола связи», но в оглавлении 44-страничного PDF её **нет** (после гл. 6 сразу гл. 7). **Нет** адресов регистров, **нет** слова команды (бит FWD/REV), **нет** масштаба задания частоты.

Поэтому **нельзя** из этого репозитория указать точный адрес вида «пиши 0x0002 в регистр 0x2000». Любые такие числа из руководств Inovance MD / Goodrive **не подтверждены** для CW100.

Практический путь:

1. Согласовать с ведущим: скорость (**PD-00**), чётность (**PD-01**), адрес (**PD-02**), стандарт/нестандарт (**PD-05**).
2. **P0-02 = 2**, **P8-13 = 0**.
3. Найти в документации ведущего (CNCDrive / CTRL-DRIVE) или сниффером карты: регистр команды пуска и бит/значение реверса, регистр частоты.
4. Проверить реверс по **F/R** и валу; задание — по **U0-28** и **U0-01**.

### Проводка

```
ПЛК A+  ----  A+   CW100
ПЛК B−  ----  B−   CW100
общий 0 В экрана / GND по схеме шины RS-485
```

Витая пара, не в одном жгуте с U/V/W. При длинной линии — согласующий резистор на концах шины (в руководстве CW100 номинал **не указан**).

### Предупреждения

- При **PD-04 = 0,0** таймаут выключен: обрыв шины **не** остановит двигатель сам по себе. Для безопасности задайте ненулевой таймаут и проверьте реакцию (руководство не расписывает, будет ли Err16 и выбег).
- Заводской **PD-05** — **нестандартный** Modbus. Если ведущий «не видит» привод, сначала пробуйте **PD-05** единицы = **1**.
- **P0-02 = 2** отключает пуск с **RUN** и с клемм (кроме функций, которые руководство отдельно не оговаривает). **STOP** при **P7-02 = 1** остаётся.

## 10. Вариант 9. Знаковое задание частоты (AI, HDI, многоступенчатое, PLC, PID)

### Когда использовать

Направление задаётся **знаком уставки частоты**, а не клеммой REV. В таблице параметров соответствующие уставки имеют диапазон **−100,0 % … +100,0 %**. Отдельной фразы «отрицательный процент = реверс двигателя» в 44-страничном руководстве **нет**. Косвенные подтверждения, что привод умеет крутить назад от знака задания:

- кривые AI/HDI допускают отрицательную «соответствующую установку»;
- **PC-00…PC-15** — задания многоступенчатого/PLC тоже **−100…+100 %**;
- **PA-08** прямо называется «частота отсечки **обратного вращения PID**»;
- **P8-13** умеет запретить реверс глобально.

Пока это не проверено на конкретном экземпляре, считайте поведение **гипотезой**, согласованной с именами параметров.

### 10.1. Аналоговый вход / HDI

Пуск по-прежнему от **P0-02** (панель / клеммы / связь). Частота — от **P0-03**.

| Код | Роль |
| --- | --- |
| **P0-03 = 2** | частота от AI1 (0…10 В / 0…20 мА, **P4-39**) |
| **P0-03 = 3** | AI2, местный потенциометр (завод) |
| **P0-03 = 4** | потенциометр панели |
| **P0-03 = 5** | импульс HDI (DI5), кривая **P4-28…P4-32** |
| **P4-13…P4-16** | кривая AI1: вход и соответствующая установка **−100…+100 %** |
| **P4-18…P4-21** | кривая AI2, то же |
| **P4-23…P4-26** | кривая AI3; завод уже **−10 В → −100 %**, **+10 В → +100 %** |
| **P4-33** | выбор кривой для AI1/AI2/AI3 |
| **P8-13** | реверс должен быть разрешён |

Пример идеи (не завод): чтобы 0…10 В на AI1 давали реверс в нижней половине, нужна кривая с отрицательной установкой на минимальном входе (например **P4-14 = −100 %**, **P4-16 = 100 %**) **и** источник, который реально уходит в зону, соответствующую минусу. Сам AI1 по таблице — **0…10 В / 0…20 мА**, то есть **однополярный**. Отрицательная частота из однополярного 0…10 В получится только если нижняя точка кривой задана отрицательной (например 0 В → −100 %, 5 В → 0 %, 10 В → +100 %). **Четырёхточечные кривые A6** в списке **P4-33** упомянуты, но группы **A6 в таблице руководства нет** — настроить 3 точки через A6 из этого текста нельзя.

AI3 в параметрах рассчитан на **−10…+10 В**, но в таблице клемм CW100 отдельной клеммы AI3 **нет** (есть AI1 и упоминание AI2 на схеме). Откуда физически берётся AI3 на этой плате — **неясно**.

### 10.2. Многоступенчатое задание и простой PLC

| Код | Роль |
| --- | --- |
| **P0-03 = 6** | многоступенчатая команда |
| **P0-03 = 7** | простой PLC |
| **PC-00…PC-15** | задания 0…15, **−100,0 % … 100,0 %** (100 % = максимальная частота **P0-10**) |
| **P4-xx = 12…15** | клеммы выбора ступени (завод DI5 = ступень 1) |
| **PC-16…PC-50** | цикл PLC, времена, единицы |
| **P8-13** | разрешить реверс, если ступень отрицательная |

Отрицательное **PC-0n** — кандидат на обратный ход на этой ступени. Подтвердите на стенде.

### 10.3. PID и «обратное вращение»

Не путать два разных «реверса»:

| Код | Имя | Это про двигатель? |
| --- | --- | --- |
| **PA-03** | Направление действия PID (0 прямое / 1 обратное) | Нет: знак регулятора процесс/обратная связь |
| **P4-00 функция 35** | Обратное действие PID | Нет: то же, с клеммы |
| **PA-08** | Частота отсечки обратного вращения PID (завод **2,00 Гц**) | **Да, про вал**: порог, ниже которого PID не уводит в реверс (типовой смысл; детальной фразы в CW100 нет) |
| **PA-24** | Макс. отклонение двух выходов PID в обратном направлении | Про скорость изменения выхода регулятора, не про клемму REV |

Если **P0-03 = 8** (частота от PID) и выход PID уходит в минус, двигатель может реверсироваться. **PA-08** ограничивает мелкий «дребезг» вокруг нуля. Для насосов/вентиляторов, которым реверс вреден: **P8-13 = 1** и/или не используйте PID как источник частоты с двусторонним выходом.

### Пошагово (общий каркас)

1. Выбрать источник команды (**P0-02**) и дать безопасный RUN.
2. Выбрать источник частоты (**P0-03**) со знаковым диапазоном.
3. **P8-13 = 0**.
4. Подать отрицательную уставку (кривая AI / отрицательный PC-xx / PID).
5. Смотреть вал и **F/R**. Если вал не реверсируется — этот канал на вашем экземпляре, возможно, берёт модуль частоты, а направление ждёт от FWD/REV. Тогда используйте варианты 4–6.

### Предупреждения

- Потенциометр 0…10 В на заводе (**P0-03 = 3**, кривая AI2 с **P4-19 = 0 %**) **не** даёт реверса сам по себе.
- Смена знака частоты на ходу = тот же удар, что FWD↔REV: смотрите **P8-12** и тормоз.

## 11. Вариант 10. Перемена двух фаз двигателя U / V / W

### Когда использовать

Крайний **электромонтажный** способ развернуть «прямое» вращение навсегда, без **P0-09**. Имеет смысл, если:

- нужно, чтобы даже при сбросе параметров на завод (**PP-01**) механика осталась «правильной»;
- или **P0-09** по какой-то причине не используют.

Руководство **не** описывает перемену фаз как метод реверса. Оно говорит только: клеммы **U, V, W** — «подключение трёхфазного двигателя»; сеть на U/V/W подавать нельзя; монтаж — при снятом питании.

Для трёхфазного асинхронного двигателя смена порядка любых **двух** выходных фаз меняет направление поля статора.

### Параметры

Не требуются. **P0-09** лучше оставить **0**, чтобы не сложить две инверсии.

### Проводка (только на обесточенном приводе)

Исходно (схема руководства): **U, V, W** → двигатель **M**, плюс заземление корпуса и двигателя.

Чтобы развернуть мотор, поменять **ровно две** жилы, например:

```
Было:   U──Uдв    V──Vдв    W──Wдв
Стало:  U──Vдв    V──Uдв    W──Wдв     (переставлены U и V)
```

Не переставлять вход **R, S, T** с этой целью.

### Пошагово

1. Снять команду пуска, **STOP**, отключить ввод, **блокировка**.
2. Ждать **≥ 3 минут**. Проверить отсутствие напряжения на **U, V, W** и шине (квалифицированный персонал).
3. Поменять две фазы на стороне двигателя или на клеммнике **U/V/W**.
4. Затянуть клеммы, восстановить землю.
5. Снять блокировку, подать питание, пуск на **малой** частоте.
6. Сверить вал с механикой. **F/R** при «прямой» команде и **P0-09 = 0** должен быть **погашен**: вы изменили физику, а не командный реверс.

### Предупреждения (критично)

- **Никогда** не переключайте U/V/W под напряжением и на вращающемся двигателе — дуга, Err01/Err13, травма.
- Не путать с входом **R/S/T**: перестановка входа не реверсирует мотор за VFD.
- После полной автонастройки (**P1-37 = 2**) смена фаз может потребовать повторить автонастройку; руководство это **не оговаривает**, но векторный контур чувствителен к модели двигателя.
- Для механизма, который нельзя крутить назад, этот метод — способ задать правильное «вперёд», а не оперативный реверс. Оперативный запрет всё равно **P8-13 = 1**.

## Вспомогательно: сигнал «сейчас реверс» наружу

Не способ задать реверс, а индикация для ПЛК/лампы:

| Код | Клемма | Функция **33** |
| --- | --- | --- |
| **P5-01** | FM в режиме FMR (**P5-00 = 1**) | Обратное вращение |
| **P5-02** | Реле **TA–TC** | то же |
| **P5-04** | **DO1** | то же |

Завод: **P5-01 = 2** (авария), **P5-02 = 0**, **P5-04 = 1** (привод работает). Реле: 250 В перем. / 3 А (cos φ = 0,4) или 30 В пост. / 1 А.

## Вспомогательно: реверс в режиме момента (группа A0)

Если **A0-00 = 1** (управление моментом), знак момента **A0-03** (−200,0 %…+200,0 %) и пределы **A0-05** (макс. частота вперёд) / **A0-06** (макс. частота назад) описывают двустороннее движение. Это не типовой реверс шпинделя/конвейера. Для CW100-T5.5GB в обычном V/F (**P0-01 = 2**, завод) группа A0 не нужна. Деталей, как именно знак момента связан с **F/R**, в руководстве нет.

## Типовые ошибки

| Симптом | Что проверить |
| --- | --- |
| Клеммы «молчат» | **P0-02 = 1**? **P4-38** совпадает с проводкой? U0-07 меняется? |
| Есть FWD, нет REV | **P8-13 = 0**? Назначена функция **2** или **5**? Не занят ли **P4-11** не тем режимом? |
| Самозапуск при включении | Клемма RUN замкнута; включить **P8-18 = 1** |
| Клавиша M-FUN ничего не делает | **P7-01** не 0? **P0-02 = 0** для вариантов 2–3? Параметр меняли на стопе? |
| Реверс с ударом / Err03 / Err06 | Увеличить **P0-18**, задать **P8-12**, проверить тормозной резистор |
| Связь не управляет | **P0-02 = 2**, PD-00/01/02/05, Err16, неверная карта регистров (её нет в этом мануале) |
| После PP-01 «съехало» направление | Завод вернул **P0-09 = 0**; физическая перемена U/V/W сохранится |
| Потенциометр не реверсирует | Заводская кривая 0…+100 %; нужен вариант 4–6 или знаковая кривая (вар. 9) |

## Пробелы и неоднозначности исходного руководства

Имеет смысл не додумывать за завод, а проверить на аппарате:

1. **Нет схем и таблиц истинности** для **P4-11** (двухпроводный 1/2, трёхпроводный 1). Имена функций «FWD или RUN» / «REV или направление» намекают на смену смысла клемм от режима, но алгоритм при конфликте FWD+REV и полярность трёхпроводного STOP в PDF не приведены.
2. **Нет главы протокола связи**, хотя она обещана во введении. Адреса регистров команды реверса неизвестны.
3. **Отрицательные %** на AI/HDI/PC формально есть; фразы «минус = реверс вала» нет.
4. Поведение **P8-13 = 1** при уже поданной команде REV не описано.
5. Влияние **P0-09** на индикатор **F/R** не описано.
6. Действует ли клеммный JOG при **P0-02 ≠ 1** без **P8-27** — не описано.
7. Удержание JOG с **M-FUN** «пока нажата» не оговорено.
8. Клемма **AI3** есть в параметрах и нет в таблице клемм корпуса.
9. Группа **A6** (кривые 4 и 5) упомянута в **P4-33**, в таблице кодов отсутствует.
10. В Err16 написано «группа FD» вместо **PD**.
11. Расхождение имён модели: шильдик **CW100-T5.5GB** vs строка таблицы **CW100-5D5-4** — та же мощность 5,5 кВт / 380 В, но это разные записи в одном документе.
12. Во введении оригинал назван «English Manual V1.0»; русская копия в репозитории — перевод той же 44-страничной таблицы, не отдельное расширенное РЭ.
