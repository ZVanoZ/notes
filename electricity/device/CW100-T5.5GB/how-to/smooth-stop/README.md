# Плавный стоп

---

* Устройство медленно стартует и останавливает двигатель. Почему?

<details>
<summary>Ответ</summary>
Это штатное поведение CW100, а не поломка. Привод не подаёт полную частоту сразу и не обрывает выход при STOP: он разгоняет и тормозит двигатель по рампе. С завода останов — с замедлением (**P6-10 = 0**), а не выбег.

Сначала на панели посмотрите **P0-17** и **P0-18**. Для CW100-T5.5GB их заводское число в 44-страничном руководстве не указано («зависит от модели»).

## Почему медленно

| Код | Назначение | Завод |
|---|---|---|
| **P0-17** | Время разгона 1 | зависит от модели |
| **P0-18** | Время торможения 1 | зависит от модели |
| **P0-19** | Единица времени рампы | **1** (0,1 с) |
| **P0-25** | База рампы | **0** = макс. частота **P0-10** (50 Гц) |
| **P6-10** | Режим останова | **0** = с замедлением |

При **P0-25 = 0** значения P0-17/P0-18 — время прохода **0 ↔ 50 Гц**. Если задание ниже 50 Гц, фактический разгон короче. **P6-10 = 1** дал бы быстрый выбег, но с завода стоит **0**.

## Если рампа уже не заводская

Чаще всего путают обычный RUN с **JOG**: завод **P8-00 = 2 Гц**, **P8-01 / P8-02 = 20 с**, клемма DI3 с завода — **FJOG**. Тогда двигатель «еле ползёт».

Ещё могут растянуть пуск/стоп: стопор по сверхтоку (**P9-05** / **P9-06**, с завода включён), другой набор Acc/Dec 2–4, запрет рампы (DI **21**), клеммы UP/DOWN (**P4-12 = 1 Гц/с**), S-кривая (**P6-07**), DC-тормоз, PID, сон/пробуждение, управление моментом.

## Как ускорить

1. Прочитать **P0-17**, **P0-18**, **P6-10**, **P6-07**; если это JOG — ещё **P8-01 / P8-02**.
2. Уменьшить **P0-17** и **P0-18** постепенно, не до нуля.
3. Оставить **P6-10 = 0**, если нужен контролируемый останов. **P6-10 = 1** — быстрый выбег по инерции.
4. Если включена S-кривая — вернуть **P6-07 = 0**.
5. После укорочения рампы смотреть аварии: **Err02** (разгон) → увеличить P0-17; **Err03 / Err06** (торможение) → увеличить P0-18 и/или проверить тормозной резистор (**≥ 90 Ом, 400 Вт** для T5.5GB).

Слишком короткая рампа бьёт по механике и на реверсе «на лету» часто даёт **Err03 / Err06**.

* Как отключить плавный стоп?

<details>
<summary>Ответ</summary>

Плавный стоп отключается сменой **режима останова** на выбег.

**Основной способ:** на панели задайте **P6-10 = 1** (выбег / Coast to stop).

После этого команда STOP сразу снимает выход инвертора: двигатель крутится по инерции и останавливается сам, без рампы **P0-18**.

**С клеммы:** назначьте входу DI функцию **8** (свободный выбег). Пока клемма активна, останов идёт выбегом, даже если **P6-10 = 0**.

**Что не делать, если нужен быстрый, но управляемый стоп.** Не обнуляйте только **P0-18**: это всё ещё торможение инвертором, только очень резкое, с риском **Err03 / Err06** и удара по механике. Для ускоренного плавного стопа уменьшайте **P0-18**, а не переключайте **P6-10**.

**Осторожно.** При **P6-10 = 1** инвертор не тормозит вал. На инерционной нагрузке останов будет долгим; тормозной резистор в этом режиме не помогает. Вернуть плавный стоп: **P6-10 = 0**.
</details>
