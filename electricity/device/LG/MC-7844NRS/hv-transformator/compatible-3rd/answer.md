# Технические характеристики для поиска сторонних аналогов ВВ-трансформатора LG MC-7844NRS

## 1. Введение и назначение

Данное руководство содержит технические критерии, допустимые диапазоны электрических параметров и габаритные требования для подбора аналогов высоковольтного трансформатора СВЧ-печи **LG MC-7844NRS** (900 Вт СВЧ, 230 В / 50 Гц) от сторонних производителей (Galanz, Daewoo, Samsung, Witol, Yunlu и др.).

---

## 3. Габаритные и конструктивные требования (Механика и монтаж)

При подборе аналога от другого производителя необходима физическая примерка по следующим механическим параметрам:

1. **Габариты основания (подошвы):**
   - Типовой размер подошвы: ~95–100 мм × 85–95 мм.
   - Межосевое расстояние между крепежными отверстиями: **80 × 90 мм** (или овальные пазы с диапазоном 75–85 мм × 85–95 мм).
2. **Габаритная высота:**
   - Высота сердечника в сборе с катушкой не должна превышать **95–100 мм**, чтобы трансформатор не упирался в кожух или вентиляционные каналы печи.
3. **Ориентация клемм и длина проводов:**
   - **Первичная обмотка:** 2 ножевых разъема Faston 6.3 мм («папа»).
   - **ВВ-вывод:** 1 ножевой разъем Faston 6.3 мм (или 4.8 мм с переходником).
   - **Выводы накала:** 2 гибких силиконовых провода высоковольтной изоляции с разъемами Faston 6.3 мм («мама»). Длина проводов должна быть **не менее 15–20 см** для свободного подключения к выводам `F` и `FA` магнетрона без натяжения.

## 4. Популярные серии сторонних аналогов для печей 900 Вт

Ниже перечислены распространенные на рынке модели трансформаторов от сторонних производителей, полностью или частично подходящие для замены трансформатора LG 6170W1D020E:

### 1. Производитель GALANZ (Китай)
- **GAL-900E-4** / **GAL-900E-1** / **GAL-900E-2**
  - *Характеристики:* 230 В / 50 Гц, 900 Вт СВЧ, CLASS 220 / CLASS 200.
  - *Совместимость:* Прямая замена по электрическим и габаритным параметрам. Одно из наиболее распространенных и надежных решений.

### 2. Производитель DAEWOO (Южная Корея / Китай)
- **XB-900-2** / **XB-900-1**
  - *Характеристики:* 230 В / 50 Гц, 900 Вт СВЧ, CLASS 200 / CLASS 220.
  - *Совместимость:* Полный аналог по мощности и посадочным местам.

### 3. Производители WITOL / YUNLU / MD (Китай)
- **MD-901EMS** / **MD-901EMS-1**
  - *Характеристики:* 230 В / 50 Гц, 900 Вт СВЧ, CLASS 200 / CLASS 220 / CLASS 250.
  - *Совместимость:* Широко применяется в печах Midea, Panasonic, Whirlpool. Полный электрический аналог.
- **YTM-900E**
  - *Характеристики:* 230 В / 50 Гц, 900 Вт СВЧ.

### 4. Производитель SAMSUNG
- **SHV-EURO1** (Samhwa) / **SHT-900**
  - *Характеристики:* 230 В / 50 Гц, 900 Вт СВЧ.
  - *Совместимость:* Полная электрическая совместимость; может потребоваться подгонка крепежных отверстий основания.

## 5. Допустимые отклонения и предупреждения

- **Использование трансформатора от печи 800 Вт (например, GAL-800E, MD-801EMS):**
  - *Электрически:* Рассчитан на меньший рабочий ток ВВ-обмотки (~300 мА вместо 380–400 мА).
  - *Последствия:* При установке в печь 900 Вт трансформатор 800 Вт будет работать с постоянной перегрузкой, быстро нагреваться (более 100 °C) и со временем уйдет в межвитковый пробой. Допускается только как временное решение.
- **Использование трансформатора от печи 1000–1100 Вт:**
  - *Последствия:* Завышенный рабочий ток приведет к перегрузке магнетрона, повышенному нагреву катода и сокращению ресурса СВЧ-излучателя.
