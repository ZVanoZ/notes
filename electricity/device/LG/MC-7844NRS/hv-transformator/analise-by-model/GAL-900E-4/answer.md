# Анализ совместимости трансформатора GAL-900E-4 с печью LG MC-7844NRS

## 1. Вводные данные и объекты сравнения

- **Целевое устройство:** Микроволновая печь **LG MC-7844NRS /00** (900 Вт СВЧ, конвекция + гриль).
- **Штатный трансформатор:** LG `6170W1D020E` / `SHV-EURO1-1` (900 Вт, класс изоляции 220).
- **Анализируемая модель:** **GAL-900E-4** (Galanz, 900 Вт).

## 3. Вердикт

**Вердикт: ПОЛНАЯ СОВМЕСТИМОСТЬ.**

Трансформатор GAL-900E-4 является одним из наиболее предпочтительных аналогов для замены штатного узла LG 6170W1D020E. Электрические параметры, посадочные размеры и тип разъемов идентичны, что позволяет установить его без каких-либо доработок.
